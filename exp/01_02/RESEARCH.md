# 研究问题与方法边界

01研究数据组对多个能力的正负作用，判断哪些组合可以共同改善；02学习可执行的行为组，让它们成为训练混合单元。一条数据可以参与多个组，原子系数的正负不能在分析前丢掉。实际更新使用原始损失的梯度，不能将字典向量直接冒充一组真实数据。

## 单域与多域的研究假设

一个领域的平均更新可能掩盖域内不同的作用。目标是检查：领域整体配比无法利用的共同机会，是否可以通过细粒度行为组恢复。A、B是数据组，不必分别等于两个领域。

固定模型的一阶响应若为A=(a,−b)、B=(−c,d)，且四个数均为正，则αA+(1−α)B同时为正需要：

```
c/(a+c) < α < d/(b+d)
```

可行区间非空当且仅当ad>bc。冲突本身不足以保证互补。这是两目标线性混合的代数条件，不是新的通用优化定理，也不保证长期排名收益。

构造例：域1含等频的A=(2,−1)、C=(0,−1)，域2含B=(−1,2)、D=(−1,0)。两个域的平均响应为(1,−1)、(−1,1)，任意领域配比都不能严格共同改善；但等权A+B=(0.5,0.5)，仍保持1:1领域比例。此例仅说明可能性，不是实际推荐实验结果。

## 02需要证明什么

原子形成的非负样本混合仍在完整样本凸包内，不能仅凭表示扩大同状态的完整可行更新集合。额外价值需要来自有限预算下更可靠的作用估计、机会发现或结构复用，必须超过普通分组、领域调配等简单对照。

E006用合法SID读出梯度的部分梯度草图学习原子，随后用完整可训练梯度估计实际作用。这不是完整梯度原子的一般验证，也没有识别真实用户兴趣的因果语义。分解重构、预测响应和最终排名收益分别判断。

## 已有工作边界

- [MAMDR](https://arxiv.org/abs/2202.12524)已有多域推荐冲突研究。
- [DoGraph](https://aclanthology.org/2026.acl-short.28/)已有梯度视角的领域与混合研究。
- [Gradient Atoms](https://arxiv.org/html/2603.14665v2)已有共享梯度行为的稀疏分解。
- [MoRec](https://arxiv.org/html/2310.13260v1)已有数据驱动的多目标推荐优化。

这些文献限定新颖性，不是本库已复现或已战胜的工作。当前结果不能支持“首次有效”“SFT/RL通用”“识别真实因果兴趣”或“达到外部SOTA”。
