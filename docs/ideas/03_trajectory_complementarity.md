# IDEA 03 — 有些样本现在无益，却是后续能力的前置条件

**定位：与 IDEA01 组合的第二候选贡献；只有静态选择解释不了的顺序效应成立时才保留。**

## 1. 问题和领域动机

推荐模型可能先需学会物品表示或约束语义，才能利用稀疏的目标用户反馈。某条样本与当前验证梯度不对齐，不代表整个训练周期无用。用户兴趣和目标权重也可能变化。但“某类数据应该先学”的直觉不是证据；重复曝光顺序、训练损失缩放、不同用户活跃度都能制造假象。

[Influence Dynamics and Stagewise Data Attribution](../papers/stagewise.md) 已研究时序归因，[DoGraph](../papers/dograph.md) 动态重构域，[MiniRec](../papers/minirec.md) 已有课程，[CAPT](../papers/capt.md) 涉及上下文适配，[phase-transition](../papers/phase.md) 的知识阈值也不能直接搬成推荐兴趣的相变。

另有新近[GLOBE摘要线索](../papers/globe.md)已经讨论多checkpoint梯度轨迹匹配，本轮未打开全文，必须进一步排查直接重合。

待检验差异不是“加课程”，而是：以跨阶段传播后的目标响应识别互补数据，并验证静态打分会错误舍弃的前置样本是否改变后续学习能力。

## 2. 精确可分析模型

固定训练顺序，二次损失

\[
\ell_t(\theta)=\frac12\theta^\top H_t\theta-b_t^\top\theta,
\quad\theta_{t+1}=\theta_t-\eta_t w_t(H_t\theta_t-b_t),
\]

H_t 对称。终端目标 L(θ_T)，设 v_T=∇L(θ_T)。链式法则给出

\[
v_t=(I-\eta_t w_tH_t)^\top v_{t+1},\qquad
\frac{\partial L(\theta_T)}{\partial w_t}
=-\eta_t v_{t+1}^\top(H_t\theta_t-b_t).
\]

证明：先对每步 θ 的 Jacobian 反向传播，再对该步权重求偏导。所有未来状态依赖已经包含于 v_{t+1}；不能错误地使用 v_t 多乘一次当前 Hessian。代码与有限差分逐步比较。

这说明当前终端方向必须经过未来学习动力学传播，单看 `∇L(θ_t)ᵀg_t` 可能不够。但未来若根据模型状态自适应改变数据顺序，公式只描述**固定策略路径的条件导数**；完整策略导数还要考虑选择器变化。

## 3. 两组数据的顺序效应

对相同步长 η 的二次损失 a,b，设初始梯度 g_a,g_b。直接展开得

\[
\theta_{a\to b}-\theta_{b\to a}
=\eta^2(H_b g_a-H_a g_b).
\]

二次情形这是精确等式。一般光滑损失在额外 Hessian 正则性下是二阶主项；不应只靠 L-smooth 就声称余项 O(η³)。若右式为零，则本尺度下没有该顺序效应；这是有意义的 null test。

在推荐解释上，顺序效应可能来自表征先修，但也可能纯粹是不同 Hessian 的优化效应。只有配合目标任务的行为干预，才可以上升到“先修能力”解释。

## 4. 可执行路线

第一层使用本库精确二次测试，核对导数和顺序差异。第二层在 tiny/小规模 LLM 上保存有限 checkpoint，用 Hessian-vector product 近似短窗口传播，窗口外 stop-gradient；明确预算和近似误差。第三层只对少量具有强候选因果链的数据组做真实补回干预，而不是追踪每条数据整个训练历史。

现有实现只有第一层；没有完整 LLM HVP 轨迹缓存流水线。原因不是认为方法不可能，而是当前交付无法把未运行的大模型轨迹工具称为已验证。后续实现规格在 `IMPLEMENTATION.md` 给出，需要重新运行真实训练后升级。

## 5. 实验、对照和停止条件

固定同一多重样本集合，仅改变顺序，且匹配总 token、学习率轨迹、优化器初始化和每组出现次数。比较随机序、先a后b、先b后a、交错、静态梯度序和时序预测序。使用独立 terminal目标评价；不要用选择器自身预测的未来值当作主要结果。

再做干预：移除所谓先修组、用相同文本长度/物品频率组替代、将学习率缩小验证顺序效应阶数、将 Hessian 构造为对易/零括号作为数值反例。若干预后终端曲线不分叉，接受PPT的 null hypothesis；若只改变学习率就消失且不存在领域行为差异，贡献收窄为优化调度，不宣称学会了兴趣机制。

## 6. 状态

`trajectory.py` 提供二次轨迹、伴随导数、顺序括号。数值等式和有限差分测试通过。真实用户长期兴趣、LLM先修能力和跨checkpoint可迁移价值均未验证。应优先作为01的区分性实验，而非立即扩张成第二个大型系统。
