# IDEA 07 — 把“兴趣饱和”拆成发现、切换与停止

**定位：独立研究线；与训练数据选择不强行捆绑。**

## 1. 原始直觉中三个不同对象

“没有新的选择”可能指推荐列表已经覆盖了当前兴趣；“不想继续看”是疲劳/停止；“换一个场景”是动作策略。三者不同。重复推荐也可能符合用户长期兴趣，不能自动标成坏行为。

[PIE](../papers/pie.md) 已结合个性化图搜索与兴趣探索，[FRec](../papers/frec.md) 已建模疲劳，[KuaiSim](../papers/kuaisim.md) 有会话相关模拟。因此PageRank、bandit、fatigue任何一个词都不能作为新贡献。

可研究的更明确问题是：在给定历史曝光和可用质量约束下，如何分开估计“新兴趣边际价值”和“用户继续消费概率”，并用可校准的策略决定是否切换场景。需要真实跨场景记录，且不能把日志时间窗口结束当作用户流失。

## 2. PageRank 是候选分布，不是用户离开的模型

取行随机转移矩阵P，个性化分布v，0≤α<1，

\[
r=(1-\alpha)v+\alpha P^\top r.
\]

映射在l1上为α收缩，所以唯一固定点存在；迭代误差几何衰减。图中没有出边的节点必须按预先指定分布补成随机行，否则概率丢失。

重启项不自动意味着探索：若v只支持旧兴趣，重启可能更集中。应显式区分利用分布pθ和新兴趣分布r_new。已覆盖兴趣集合C下，简化模型的下一次发现概率为 `Σ_{c∉C}r_c`；这只解释覆盖，不代表情绪或留存。

## 3. 停止与跨场景转移

用状态s表示近期曝光、间隔和反馈，Q为不包含停止吸收态的sub-stochastic转移矩阵。即时reward向量r，折扣γ，则

\[
 v=r+\gamma Qv=(I-\gamma Q)^{-1}r.
\]

γ<1且Q行和≤1时可用Neumann级数；γ=1还需谱半径ρ(Q)<1。若存在永不停止的闭合类，逆不一定存在，本库会拒绝不满足条件的求解。真实Q的估计必须处理右删失；本代码只有给定Q求值，没有宣称已从KuaiSAR正确识别退出风险。

## 4. 一个可以审计的策略改进起点

定义混合策略

\[
q_\epsilon=(1-\epsilon)p_\theta+\epsilon r_{new}.
\]

若对每个候选的reward有有效下界l，要求 `qεᵀl≥τ`，这是ε的线性约束。代码解出允许的最大ε。因为效用在分布上是线性的，在下界事件成立时可保证这个**单步目标**不低于τ。

这不保证长期value、留存或公平；错误的下界也不能提供安全性。图分数不是reward置信下界，二者不能互换。跨场景强推不感兴趣内容可能损害用户，应约束频率与可退出，不把强制曝光当作“多样性提高”。

KL约束另一种推导为 `max_q qᵀu−T KL(q||p)`，拉格朗日给出 `q_i∝p_i exp(u_i/T)`。它是乘法tilt，与上述加法混合不是同一个策略。

## 5. 数据、评价与新颖性门槛

KuaiSAR可研究同用户搜索/推荐转换；KuaiRand可分析部分多反馈曝光；KuaiSim可先验证已知停止机制下策略值。必须公开训练图仅使用决策前数据、候选集合如何形成、场景定义是否变化。历史覆盖不等于有用新发现，至少同时报告相关性、被用户接受的新类别、退出/删失以及分层效用。

危险基线：标准PPR、固定ε混合、简单最近曝光惩罚、PIE式探索、FRec式序列模型、仅按新颖度重排。若新方法只比无探索基线好，不足以说明贡献。若在Q错设或真实日志验证时收益消失，停止留存主张。

## 6. 本轮实现与状态

`exploration.py` 有PPR、吸收价值、单步下界混合、KLtilt和覆盖概率；测试包括悬挂节点、γ=1不可逆、不可满足的质量约束和分布归一化。可以复现数学状态机示例，未运行真实推荐交互或拟合退出模型。现阶段只通过机制原型，不通过新颖性/真实留存效果。
