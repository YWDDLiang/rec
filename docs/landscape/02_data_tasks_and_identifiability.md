# 数据、任务与可辨识性：每条idea究竟需要哪些信息

## 一、三个不能混用的目标

预测“历史上记录了什么”是观察预测；评估“换政策会发生什么”是反事实政策评价；寻找“哪种数据让模型更会推荐”是学习干预。三者的数据、权重和随机性不同。删除训练样本的反事实不等于改变用户曝光的反事实。

| 方向 | 最低数据要求 | 缺失时允许结论 | 不允许结论 |
|---|---|---|---|
| 01联合机会 | 多目标标注、独立参考、可算更新方向 | 给定经验矩阵的局部诊断 | 全人群共同改善、Pareto前沿必提升 |
| 02原子 | 梯度、模板/前缀/历史等可观测因素 | 指定因素空间不变性 | 真实兴趣的因果识别 |
| 03时序 | 固定训练顺序/checkpoints及终端目标 | 条件训练轨迹导数 | 自适应长期训练全导数 |
| 04观测 | 缺失标记、日志策略或其可识别模型 | MAR条件估计或描述性分析 | 未记录动作的真实效用 |
| 05RL | 完整rollout组、policy概率、reward向量 | 固定组级surrogate估计 | 真实用户长期满意度 |
| 06获取 | 获取前特征、验证后的标签、成本/来源 | oracle机制与验真门禁 | 免费知道未标注梯度 |
| 07探索 | 曝光序列、场景、停止/删失定义 | 已知模拟器里的策略值 | 日志结束就是疲劳/流失 |
| 08解码 | 合法目录、injective SID、目标分布 | 有限目录抽样一致 | 大目录速度和Top-K相同 |
| 09科学组合 | 接口/资源/证据/时间、独立执行或专家 | 已验证组合可行性 | LLM推荐即能复现 |
| 10实验 | 条件、失败类型、独立计算/实验 | 指定统计模型信息增益 | 稳定、可合成、发现新机理 |

## 二、公开数据的实际适用位置

[Amazon Reviews 2023](../papers/amazon23.md)：适合文本和next-item SFT、冷启动、类别覆盖；没有完整曝光反事实，不适合直接证明CTR/疲劳。[KuaiRand](../papers/kuairand.md)：适合多反馈与部分曝光分析；按场景核对标签定义、随机实验设计、Pure完整性、文字覆盖，不能使用整月聚合当作事件时刻已知特征。[KuaiSAR](../papers/kuaisar.md)：适合搜索/推荐转换，但包含选择使用双服务用户的过程。[KuaiSim](../papers/kuaisim.md)：先做机制测试，不把模拟器泛化等同真实用户。

[RecIF-Bench/OpenOneRec](../papers/openonerec.md)：考察公开推荐模型能力与指令任务，需区分基础推荐和多反馈效用；[DataFinder](../papers/datafinder.md)/[SciRepEval](../papers/scirepeval.md)：作为科学检索基础，但仍需新建兼容/可执行证据，而非直接把相关性标签当执行成功。

## 三、规范拆分与时间

严格顺序：train用于拟合；selection用于配置选择；calibration用于估计误差/阈值；test只在方法冻结后评估。当前tiny数据只有train/selection/test，因此没有独立calibration层，不能套用独立误差界声称泛化已认证。正式实验须补该层，或交叉拟合并保持最终外层测试完全独立。

用户级泄漏：同用户跨时间可以是合理部署场景，但必须按全局时间切分并仅使用过去历史；冷用户泛化需额外按用户切分，不把两种场景混写。物品目录可以预先公开但元数据必须在时间点可用；test出现的新物品不能用test反馈训练SID或热门统计。

本库KuaiRand适配器使用逐事件CSV的显式字段，不读取整月统计。历史是滚动已观测事件，可包括较早selection/test时期的历史上下文，**不使用未来标签训练**；这对应rolling logged-history评价，不是固定起点生成完整未来会话。训练器对字段、缺失和时间进行拒绝式验证。

## 四、成本、指标与统计

推荐相关性：在定义正确候选集时报告Recall/NDCG；反馈预测报告BCE/Brier及适当的AUC等；业务多目标应为不同反馈/资源/公平约束，不是同一指标不同K。多目标结果展示固定配比、经验Pareto前沿、最差目标/场景与主目标不劣约束。Hypervolume先固定方向、归一化和reference point。

总成本包括候选评分、逐例梯度、dictionary、优化器、pilot、生成后丢弃rollout、外部标注与训练。减少选中样本比例不是默认减少等同比例的计算。当前tiny加权全池训练没有样本执行层的节约，不报告压缩率或训练加速。

统计以用户/会话作为重采样单元，避免将同用户交互误当独立。多个随机种子报告分布；当前3种子只用于工程检查，不能根据均值差直接说显著。失败结果和选择集过拟合必须同表展示。
